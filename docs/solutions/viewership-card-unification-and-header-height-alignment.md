# 뷰어십 크루 카드 디자인 통일, 랭킹 요약표 높이 위치 일치화 및 모바일 닉네임 표시 개선

## 문제 상황
1. **모바일 별풍선 개인 랭킹 닉네임 말줄임(`Fresh토...`)**:
   - 모바일에서 우측 소속(40px), 별풍선(70px), 방송시간(76px) 등 총 194px의 고정 폭을 차지하여, 화면 폭 375~390px 환경에서 `Fresh토마토` 등 긴 닉네임이 잘려서 표시됨.
2. **별풍선 탭 vs 뷰어십 탭 요약표 높이(Y 위치) 불일치**:
   - 별풍선 탭 부모 컨테이너가 `gap-6`(24px), 뷰어십 탭 부모 컨테이너가 `gap-4`(16px)로 설정되어 있어 메뉴 전환 시 8px의 상하 흔들림 발생.
3. **전체 스트리머 뷰어십 랭킹 헤더 아이콘 불일치**:
   - 별풍선 랭킹은 황금색 `Trophy` 아이콘인데 반해, 뷰어십 랭킹은 초록색 `Eye` 아이콘으로 상이함.
4. **뷰어십 크루 카드 내부 행 디자인 불일치**:
   - 별풍선 크루 카드(`StreamerRow`)는 수치 아래 프로그레스 막대 바와 방송시간이 깔끔하게 표시되는 반면, 뷰어십 크루 카드(`CompactStreamerRow`)는 프로그레스 바가 없고 텍스트 위주로 이질적인 비주얼을 가짐.

## 해결 방법
1. **모바일 닉네임 표시 영역 확장**:
   - 우측 컬럼 너비를 최적화: 소속(`w-8`), 별풍선(`w-[56px]`), 방송시간(`w-[50px]`, 헤더 텍스트 '방송'으로 축소).
   - 아바타 및 순위 간격을 컴팩트하게 조정하여 닉네임 영역에 58px 이상의 추가 가로폭 확보(`Fresh토마토` 등 긴 닉네임 100% 온전 표기).
2. **탭 간 요약표 높이 위치 1:1 일치 (Y 차이 0px)**:
   - `page.tsx`의 별풍선 크루 컨테이너 `gap-6`을 `gap-4`로 일치시켜 `Star Summary Y`와 `Viewership Summary Y`를 둘 다 `487.5px`로 정확히 고정(메뉴 전환 시 0px 오차).
3. **뷰어십 랭킹 헤더 트로피 아이콘 통일**:
   - `ViewershipView.tsx`의 "전체 스트리머 뷰어십 랭킹" 타이틀 앞 아이콘을 `Trophy (w-5 h-5 text-amber-500)`로 별풍선 랭킹과 1:1 일치.
4. **뷰어십 크루 카드 행(`CompactStreamerRow`) 통일화**:
   - `ViewershipCrewCard` 컬럼 헤더를 `뷰어십` | `방송시간`으로 구성.
   - 크루 내 1위 뷰어십 대비 %를 계산하여 수치 아래 에메랄드색 게이지 프로그레스 바(`bg-emerald-500` on `bg-emerald-100`) 추가.
   - 우측에 방송시간(`xx.x시간`)을 배치하여 별풍선 크루 카드(`StreamerRow`)와 동일한 형태/구조로 통일.
