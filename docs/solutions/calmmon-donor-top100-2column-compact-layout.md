# 캄몬스타즈 후원 랭킹 TOP 100 압축 및 2열(2줄) 컴팩트 그리드 레이아웃 개편

## 1. 개요 및 배경
- **문제점 / 요구사항**:
  1. 기존 단일 와이드 1열 테이블 형태는 페이지당 20명의 행이 세로로 길게 나열되어, 모바일 및 데스크톱 모두에서 한 화면에 다 들어오지 않고 세로 스크롤을 많이 해야 하는 불편함이 있었음.
  2. 사용자의 추가 개선 요청:
     - 랭킹 범위를 **TOP 100**으로 압축.
     - "방송시간", "스폰 판수" 탭과 마찬가지로 **2줄(2-Column Grid) 레이아웃**으로 좌우 분할하여 한 화면에 쏙 들어오는 컴팩트한 뷰 제공.

---

## 2. 해결 방안 및 아키텍처

### 2.1 2-Column Grid (2열 분할) 레이아웃 (`src/components/calm/CalmmonCard.tsx`)
1. **화면 1페이지 분량에 딱 맞춘 좌/우 10행 분할**:
   - `donorPageSize = 20` (5개 페이지: 1~20위, 21~40위, 41~60위, 61~80위, 81~100위).
   - 각 페이지에서:
     - **왼쪽 컬럼**: 해당 페이지의 앞 10명 (예: 1페이지 1~10위, 2페이지 21~30위).
     - **오른쪽 컬럼**: 해당 페이지의 뒤 10명 (예: 1페이지 11~20위, 2페이지 31~40위).
   - `grid grid-cols-2 divide-x divide-slate-100` 구조로 기존 남자(6명)/여자(11명) 테이블과 동일한 2열 규격을 유지.
   - 10개 행 기준 높이가 약 350px에 불과하여 모바일 화면에서도 아래로 스크롤할 필요 없이 한눈에 전체 20명이 시원하게 들어옴.

2. **컴팩트 타이포그래피 & 스트리머 미니 아바타**:
   - 행 높이를 `py-1 sm:py-1.2`로 고밀도 패딩 설정.
   - 1위(👑), 2위(🥈), 3위(🥉) 전용 메달 및 은은한 하이라이트 배경.
   - 주 후원 멤버: 스트리머 미니 원형 아바타(16px)를 기본 노출하고, 데스크톱(`md:inline`)에서는 텍스트 닉네임을 병기하여 공간 낭비 방지.
   - 후원자 닉네임: `truncate` 처리로 좁은 화면에서도 텍스트 줄바꿈 없이 미려하게 정렬.

3. **TOP 100 데이터셋 최적화**:
   - `scripts/sync-calmmon-donors.mjs`에서 상위 100명으로 슬라이싱.
   - `src/data/calmmonDonors.json`: 2026-10 및 2026-09 모두 TOP 100으로 최적화하여 로딩 번들 크기 경량화.
   - 탭 헤더 뱃지: `후원 랭킹 · TOP 100 (1/5P)`와 같이 현재 페이지 상태를 즉시 파악 가능.
   - 페이지네이션: 총 5페이지(`◀ 이전 1 2 3 4 5 다음 ▶`)로 한 줄에 깔끔하게 배치.

### 2.2 반응형 모바일 UI 개편 및 데스크톱 높이 1:1 일치화
1. **모바일 가독성 개선 (모바일 1열 풀 너비 뷰)**:
   - 모바일 좁은 화면(약 360~390px)에서 2열 그리드로 쪼갤 경우 각 열이 170px로 지나치게 좁아져 후원자 닉네임이 0px로 찌그러지고 스트리머 이름이 숨겨지는 문제가 발생함.
   - **반응형 분기**:
     - **모바일(`block md:hidden`)**: 1열 풀 너비 리스트로 전환하여 후원자 닉네임, 주 후원 스트리머 아바타 + 이름 텍스트, 후원 별풍선 개수가 1줄에 짤림 없이 선명하게 보이도록 개편.
     - **데스크톱(`hidden md:grid`)**: 기존 좌 10명 / 우 10명 2열 컴팩트 그리드 유지.
2. **데스크톱 카드 높이 일치화 (Zero Layout Shift)**:
   - 사용자가 불필요한 하단 요약 카드(3개)를 제거하길 원하면서도, 다른 탭(스폰 판수 등 777px)과 탭 전환 시 높이가 덜컹거리지 않도록 "밑에 내용이 없어도 크기를 맞춰달라"고 요청.
   - 데스크톱 전용 하단 스페이서(`hidden md:block h-[113px] bg-slate-50/80 border-t border-slate-200`)를 적용하여 내용 없이도 전체 카드 높이를 **777px로 1px 오차 없이 1:1 일치**시킴.

### 2.3 컬럼 수직 정렬 및 색상 피로도 개선
1. **헤더와 행 간 정렬 불일치 및 컬럼 충돌 해결**:
   - 기존에는 서브헤더와 행 내부 요소가 느슨한 flex gap으로만 배치되어 수직 정렬이 어긋나고, 유효하지 않은 패딩 클래스로 인해 1열과 2열의 경계선에서 `후원 별풍`과 `11~20위` 글자가 서로 맞닿는 현상이 발생함.
   - **해결 방안**:
     - 주 후원 멤버 컬럼(`w-[80px] sm:w-[84px] text-center`)과 후원 별풍 컬럼(`w-[76px] sm:w-[80px] text-right`)의 고정 폭을 헤더와 행에 1:1로 동일하게 부여.
     - 서브헤더에도 행과 동일한 좌우 내부 패딩(`px-2 sm:px-2.5`) 및 컨테이너 패딩(`p-3 sm:p-4`)을 적용하여 수직 수평 1px 단위 정렬 완성 및 50px 이상의 충분한 열 간격 확보.
2. **색상 피로도 해소 (네온 핑크 제거 및 슬레이트 톤 정돈)**:
   - 모든 행에 빽빽하게 노출되던 과도한 핫핑크 뱃지와 핑크색 숫자(`text-pink-600`)를 제거.
   - 주 후원 스트리머 뱃지를 부드러운 `bg-slate-100 text-slate-700 border-slate-200/90` 뉴트럴 톤으로 변경.
   - 별풍선 숫자를 1위(금빛 `text-amber-600`), 2위(은빛 `text-slate-700`), 3위(동빛 `text-amber-800`), 4위 이하(선명하고 단정한 `text-slate-800 font-extrabold`)로 일관성 있게 정돈하여 시각적 안정감 극대화.

## 3. 검증 결과
- **테스트**: `vitest run` 15개 스위트, 57개 단위 테스트 전체 통과.
- **빌드**: `npm run pages:build` Next-on-Pages 최적화 완료.
- **프로덕션 배포**: Cloudflare Pages 프로덕션 배포 완료 (`https://soop-star-naksoopyo.pages.dev/calm`).
- **시각 검증**:
  - `aligned_donor_desktop.png`: 서브헤더와 행의 주 후원 멤버, 후원 별풍이 1px 단위로 수직 정렬되고, 눈이 편안한 슬레이트/다크 톤 적용 확인.
  - `aligned_donor_mobile.png`: 모바일에서도 닉네임, 스트리머 뱃지, 별풍선 숫자가 정렬 기준선에 맞춰 선명하게 배치됨 확인.
