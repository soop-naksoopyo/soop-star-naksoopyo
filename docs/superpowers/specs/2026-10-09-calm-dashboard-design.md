## 1. 요구사항 및 범위

### 1.1 대상 멤버 (총 17명) 및 생일 메타데이터

(엠블럼 뱃지는 사용자 요청에 따라 제외)

### 1.2 탭 구성 및 데이터 요구사항
1. **🎈 별풍선 (활성화)**:
   - 우리 서비스(`/api/stats`)의 캄몬 17명 월간 누적 별풍선 데이터 연동
   - 남/여 내림차순 정렬
   - 상위 5% (초록), 상위 10% (노랑), 수장 (빨강) 배지
   - 하단 합계: 전체 합계, 여자 평균, 전체 평균
2. **⏱️ 방송시간 (활성화)**:
   - 우리 서비스(`/api/stats`)의 17명 방송시간 데이터 연동
   - 남/여 방송시간 포맷팅 (`HH:MM:SS` 또는 `XX.X시간`)
   - 하단 합계: 전체 방송시간, 여자 평균, 전체 평균
3. **👀 뷰어십 (활성화)**:
   - 우리 서비스 뷰어십 데이터 연동 (평균 시청자수 및 뷰어십 지표)
   - 남/여 정렬 및 하단 전체/평균 통계
4. **⚔️ 스폰 판수 (비워놓음)**:
   - 사용자 요청에 따라 데이터 빈 상태(준비 중 / 0판 표기 및 '연동 준비 중' 배지)로 처리
5. **👑 후원 랭킹 (비워놓음)**:
   - 사용자 요청에 따라 데이터 빈 상태(준비 중 / '연동 준비 중' 배지)로 처리

## 2. 아키텍처 및 컴포넌트 설계

### 2.1 파일 구조
```
src/
├── app/
│   └── calm/
│       └── page.tsx              # /calm 메인 진입 클라이언트 컴포넌트
├── components/
│   └── calm/
│       ├── CalmmonCard.tsx       # 풍고 룩앤필 2열 분할 카드 메인
│       ├── CalmmonHeader.tsx     # 캄몬 헤더 및 날짜/업데이트 표시
│       ├── CalmmonTabs.tsx       # 5개 탭 전환 버튼
│       └── CalmmonSummary.tsx    # 하단 3칸 합계/평균 요약 박스
└── lib/
    └── calmmonData.ts            # 캄몬 17명 메타데이터 (성별, 수장여부, 생일 등) 및 집계 유틸
```

### 2.2 데이터 흐름 (Data Flow)
1. `src/app/calm/page.tsx` 마운트 시 기존 `/api/stats` (및 뷰어십 API) 호출.
2. 캄몬 17명의 `soopId`를 기반으로 현재 통계 데이터 매핑.
3. 남성(6명) / 여성(11명)으로 분할하여 활성 탭 기준 내림차순 정렬 및 상위% 티어 계산.
4. 전체 합계, 여성 평균, 전체 평균을 산출하여 실시간 카드에 전달.
5. 우측 상단 `[📸 1클릭 캡처/복사]` 기능으로 와이고수 등 커뮤니티 공유 지원.

## 3. 검증 계획
1. **단위/타입 검증**: `npm run build` 및 TypeScript 에러 없음 확인.
2. **로컬 렌더링 검증**: `/calm` 진입 시 17명 데이터가 정상 렌더링되며 탭 전환이 매끄러운지 확인.
3. **배포 및 라이브 검증**: `npm run deploy` (Cloudflare Pages 배포) 완료 후 `https://soop-star-naksoopyo.pages.dev/calm`에서 실시간 데이터 확인.
